## Appendix 1: Scope of Refactoring Work

The following list was generated by patching [weeder](https://hackage.haskell.org/package/weeder) to find all functions that reference any of the types that would be required to change (notably the acid-state generated types, the PackageIndex and Users.Users.). Each was then manually reviewed to determine the expected scope of change required to patch.

The edit required is summarized as:

* **Remove**: this function can be removed  
* **Touch**: this function will require minor edits  
* **Reimplement**: this function should be reimplemented to talk directly to the database  
* **Major rewrite**: this function uses acid-state functionality that cannot trivially be ported, and thus must be entirely rewritten.  
* **Dramatic type change**: this function requires a dramatic type change (usually moving from pure to IO.) As such, it likely has downstream effects.
